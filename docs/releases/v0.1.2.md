Tables as grids, safer handling of pictures, files and links, and many fixes.

Tables show as grids in the text, between the paragraphs, and you write in
their cells as anywhere else: `Tab`, `Enter` and the arrows go from cell to
cell, handles select, move and open menus for rows and columns, and blocks of
cells copy and paste to and from spreadsheets. **Show as Markdown** shows one
table's pipes, and **Tables** in Preferences turns grids off.

Pictures are recognised by their contents, and an SVG never draws other files
from your computer. HTML and EPUB exports carry self-contained drawings, and
exports carry only real bibliography and style files and list what they copy.
Linked folders that lead outside your library are shown but not walked,
searched or changed, and saving at a symbolic link asks first. Link
confirmations always show the host, and **Show them** remembers the hosts a
document's web pictures come from. The math and diagram helpers run with
reduced access, and `parch check --json` reports their protections. Large or
deeply nested documents, bibliographies and pastes stay within memory and time
limits, reported by **Check document**. Touchpad scrolling follows the fingers
and glides.

See the changelog for the full list.

### Install

Download the package for your machine, check it, and install it:

```sh
release=https://github.com/willykev/parch/releases/latest/download
arch=$(uname -m)
sums=SHA256SUMS-$arch
curl -fLO "$release/parch-writer-$arch.pkg.tar.zst" &&
  curl -fLO "$release/$sums" &&
  sha256sum -c --ignore-missing "$sums" &&
  sudo pacman -U "parch-writer-$arch.pkg.tar.zst"
```

The package is `parch-writer`; the command is `parch`. An unrelated AUR
package is named `parch`, and the two cannot be installed together. The
packages are unsigned; `SHA256SUMS`, `SHA256SUMS-aarch64` and
`SHA256SUMS-x86_64` record the checksums.

To build from source instead:

```sh
git clone --branch v0.1.2 https://github.com/willykev/parch.git
cd parch
bin/install
```

The attached `PKGBUILD` also builds from the versioned source archive and
checks its SHA-256 hash. Run `makepkg -si` in a folder containing that recipe.
