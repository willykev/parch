### Install

Download the package for your machine and install it:

```sh
curl -LO "https://github.com/willykev/parch/releases/latest/download/parch-writer-$(uname -m).pkg.tar.zst"
sudo pacman -U "parch-writer-$(uname -m).pkg.tar.zst"
```

The package is `parch-writer`; the command is `parch`. An unrelated AUR
package is named `parch`, and the two cannot be installed together. The
packages are unsigned; `SHA256SUMS` and `SHA256SUMS-x86_64` record the
checksums.

To build from source instead:

```sh
git clone --branch v0.1.1 https://github.com/willykev/parch.git
cd parch
bin/install
```

The attached `PKGBUILD` also builds from the versioned source archive and
checks its SHA-256 hash. Run `makepkg -si` in a folder containing that recipe.
