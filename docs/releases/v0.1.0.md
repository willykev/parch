First public release of parch for Omarchy.

Write Markdown with its punctuation in view, and read it beside the text as a
preview with coloured code, math, Mermaid diagrams, footnotes and citations.
parch saves a moment after you pause, keeps unsaved text through a crash,
keeps earlier versions, and shows both sides when a file changes on disk.
Includes export to PDF, Word, EPUB, HTML and Markdown, printing, spell
checking, focus mode, optional Vim keys, a command palette, an interactive
Markdown guide, and a command line for checking, rendering and exporting.

### Install

Download the package for your machine and install it:

```sh
curl -LO "https://github.com/willykev/parch/releases/latest/download/parch-writer-$(uname -m).pkg.tar.zst"
sudo pacman -U "parch-writer-$(uname -m).pkg.tar.zst"
```

The package is `parch-writer`; the command is `parch`. An unrelated AUR
package is named `parch`, and the two cannot be installed together. The
packages are unsigned; `SHA256SUMS` and `SHA256SUMS-x86_64` record the
checksums.

To build from source instead:

```sh
git clone --branch v0.1.0 https://github.com/willykev/parch.git
cd parch
bin/install
```

The attached `PKGBUILD` also builds from the versioned source archive and
checks its SHA-256 hash. Run `makepkg -si` in a folder containing that recipe.

### Scope

Documents are ordinary Markdown files on this machine; there is no account
and no sync. Pictures from the web are shown only when you allow them. The
interface, the guide and spell checking are in English.
